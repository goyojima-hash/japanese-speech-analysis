# 時刻検証の試聴補助: 要件

人が音声を聞いて時刻を確認する負担を減らす。機械候補を人手正解に変換しない。

- 既存benchmarkの音声ハッシュを照合し、候補区間の前後に1秒の余白を付けたWAVを新規フォルダへ保存する。
- 確認表CSVに元音声上の時刻、文字範囲、文字起こし、試聴音声の開始位置を保存する。正解時刻・確認者は空欄。未対応候補は元音声を確認するように明記する。
- 出力の波形・クリップ時刻は機械由来で、正解ではない。切り出し時刻に境界が入りきらない場合は元音声を確認する。
- 元音声、予測、正解JSONを変更しない。既存出力先は上書きしない。失敗時には完了マニフェストを作らない。
- 5モジュール・Judgeの通常経路、採点結果、モデル依存は変更しない。
