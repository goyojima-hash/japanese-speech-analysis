# 音響時刻の比較検証: 要件

- 現行のCTC argmax時刻と新しいCTC Viterbi時刻を、同じ推論の音声・logits・ひらがな文字起こしで保存する。
- 音声ハッシュ、モデルrevision（不明なら明記）、ライブラリ版、録音長を記録する。通常の評価経路は維持する。
- 機械候補の時刻と人手の正解時刻を別フィールドに置く。文字起こしと対象区間の両方が人手確認済みの場合だけ採点する。
- 正解未入力なら結果は未検証、誤差はnull。正解を推定値から自動作成しない。
- 文字オフセットは同一文字列上だけで照合する。音声や文字起こしが異なる結果を黙って採点しない。
- 開始・終了それぞれの誤差、MAE、中央値、95パーセンタイル、対応率、1秒超の大外れ数を報告する。対応不能も全対象区間の分母に残す。
- 初期比較は50/100/200/500msの幅を併記する。採用可否の基準は今回の測定ツールでは決定しない。
- ローカル3音声は初期の疎通セット。録音形式と条件は人手で記入し、対話・重なり発話の検証を済ませたと扱わない。
