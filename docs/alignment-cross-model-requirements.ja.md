# 別モデルによる時刻候補比較: 要件

人手正解が未入力でも、人が確認すべき不一致区間を絞る。モデル間差を人手正解への誤差・精度・CEFR評価として報告しない。

- 既存3音声と保存済みのひらがな文字列をそのまま比較に使う。音声SHA-256、録音長、文字列・文字範囲の一致を確認する。
- 比較側に`jonatasgrosman/wav2vec2-large-xlsr-53-japanese`の固定改訂を使う。モデルの版・デバイス・依存版を保存し、文字を黙って削除・置換しない。
- 共通のCTC整列アルゴリズムに別の学習済み重みから得たlogitsを入力する。今回WhisperX本体は導入しない。
- 区間ごとに開始・終了のモデル間差を保存し、最大絶対差が大きい区間から確認候補一覧を作る。採点不能・未対応も件数に残す。
- 元dataset・gold・5モジュール・Judgeは不変。モデル出力は人手正解・評価結果へ流用しない。新規出力先のみ、途中失敗を完了扱いしない。
