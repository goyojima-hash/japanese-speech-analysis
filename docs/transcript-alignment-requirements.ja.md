# 文字起こし・音声時刻対応の要件

## 利用者の目的

一つの録音に複数設問の回答が続く場合や対話音声の場合、どの音声区間が文字起こしのどの範囲に対応するかを確認できるようにする。自動候補を人手確認済みの回答・話者・設問対応と混同しない。

## 必須条件

- 既存の共通Evidence、５つのFact Module、Judgeの採点結果とAI呼び出し回数を変えない。
- 日本語文字起こし上の半開区間 `[start_offset, end_offset)` と秒単位の時刻区間を、来歴と状態付きで表す。
- モーラ時刻のラベルが文字起こしの先頭から厳密に一致する場合だけ候補を生成する。不一致・不正時刻・欠測では捏造せず保留する。
- 一致した先頭部分だけなら部分対応とし、未対応の残りを明示する。
- Interactionは時刻区間の回答候補へ文字範囲候補を添えるだけで、設問・話者・回答の確定は行わない。
- キャッシュ済み `evidence.v1` の読込と旧API/CLI入力を維持する。新しい依存モデルは追加しない。
- 文字起こし自体が間違う可能性、時刻が未較正であること、音声重複を扱わないことを公開結果に明示する。
