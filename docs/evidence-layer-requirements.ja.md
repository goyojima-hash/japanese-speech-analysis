# 共通Evidence層 要件

## 目的

5つの発話評価軸モジュールが共有できる、バージョン付き・不変の `EvidenceBundle` を導入する。v1 は既存のFluencyと語彙Rangeに対応するが、スコア、CEFRレベル、正誤判定、LLM出力は作らない。

## 必須要件

- 音声ごとに、音源来歴、ひらがな／ローマ字文字起こし、VAD発話・ポーズ区間、モーラ時刻、抽出モデル来歴を一度だけ抽出する。
- 文字起こしごとに、トークン、文字オフセット、見出し語、読み、品詞、トークナイザ来歴を一度だけ作る。
- APIの既存レスポンスの事実項目とRange出力を維持する。ただし、解釈値だった旧 `fluency_grade` は意図的に除外する。
- API経路のRangeは共通トークンを使い、再トークン化しない。
- JSONキャッシュは明示的に有効化した場合だけ利用する。学習者の音声内容を含むため、既定で永続化しない。
- 共通層・各モジュールは、grade、CEFR、正誤ラベル、Judge結論を出力しない。
- Accuracy用のASR信頼度／アラインメント、Interaction用の話者・ターン、Coherence用の節分割は、v1で捏造せず未対応能力として明示する。

## 受け入れ基準

- API既存テストが通る。
- 共通トークンをRangeが一度だけ使うテストがある。
- キャッシュキーが音声内容、前処理バージョン、モデル来歴で変わるテストがある。
- キャッシュヒットで再抽出しないテストがある。
- 既定の実行ではキャッシュファイルを書かない。
