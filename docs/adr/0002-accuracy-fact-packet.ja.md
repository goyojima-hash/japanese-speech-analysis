# ADR-0002: 正確さは正誤分類器ではなくFactPacketとする

## 決定

共有Bundleに任意ASRアラインメント事実を追加し、正確さモジュールは未較正CTC観測、形態素観測、明示的参照文との任意差分だけを返す。正誤、スコア、CEFR、訂正、LLM結論は返さない。

## 理由

CTC確率はASRモデルの不確実性であり、学習者の正確さではない。自由発話に参照文がないことも多い。事実と来歴を残し、意味づけは後段AI Judgeに限定する。

## 結果

- 利点: モジュール独立性、監査性、早すぎる評価の防止。
- コスト: 信頼度較正と音素分析は別途検証が必要。
- 安全策: すべてのASR観測に導出方法・来歴・較正状態を付け、ない能力は明示する。
