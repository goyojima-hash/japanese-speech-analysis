# ADR 0003: モデルプロバイダーより先に決定的なCoherence事実基準線を作る

## 状態

設計として採用。実装は保留。

## 背景

J-GRADEにはCoherenceモジュールが必要ですが、出荷済みのFluency、Range、Accuracy事実を守る必要があります。共有Evidence v1には日本語文字起こし、文字オフセットを持つSudachiトークン、ポーズ区間があります。一方、検証済みの句読点、係り受け、共参照、トークン時刻対応はありません。

## 決定

Evidence v1の上に決定的で事実専用のCoherence収集器を作ります。明示接続表現、保守的な候補単位、単位間の語彙反復、コピーしたポーズ区間を報告します。新モデルを使わず、共通Evidenceも変更しません。

KWJAは任意の観測プロバイダーとして保留します。出力には来歴を付け、共有Evidenceの置換やレベル判定に使いません。

## 結果

- 良い点: 回帰面が小さい、出力が決定的、実行時モデル依存追加なし、教師レビューしやすい。
- 注意点: v1には暗黙関係、係り受け、共参照の観測がなく、単位は保証された文ではなく候補です。
- ガードレール: 決定的観測も将来モデル観測も、品質点や学習者誤り判断を含めません。
