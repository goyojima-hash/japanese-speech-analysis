# ADR-0001: バージョン付き共通Evidence層を採用する

## 状態

採用。

## 背景と決定

独立して選択できる5軸モジュールには、同じ音声、文字起こし、時刻、形態素が必要である。各モジュールで抽出を繰り返すとコストと不整合が増えるが、共通採点層はモジュール独立性を壊す。

そこで不変・バージョン付きの薄いEvidence層を作り、客観的事実と来歴だけを扱う。各モジュールは他モジュールを呼ばずEvidenceを消費する。AI Judgeが後段で事実を評価する。

## 結果

- 利点: 一貫性、モジュール選択、前処理再利用、監査可能な来歴。
- コスト: スキーマ進化と能力有無の明示が必要。
- 対策: 追加的スキーマ、能力マーカー、任意キャッシュ、互換アダプター。
