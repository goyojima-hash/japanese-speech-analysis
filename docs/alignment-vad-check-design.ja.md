# 時刻候補とVADの照合: 設計

`alignment_vad_check.py`の独立コマンドでbenchmarkを読み、元音声のSHA-256と16kHz再読込長を照合する。既存依存のSilero VADモデルを1回ロードして、サンプル位置の出力から秒へ変換する。しきい値0.5・最短発話250ms・最短無音100ms・発話余白30msを明示して記録する。丸めた秒を返す通常Fluencyの関数は変更せず、別の出力を作る。

計算は純粋関数に分離する。発話区間は録音長内の非重複・時系列区間とする。文字単位も録音長内の非重複・単調な文字/時刻であることを確認する。VAD区間の和集合との重なりを計算して、fully_inside/partially_outside/fully_outsideを観測分類として出す。これらはVADとの関係だけを示し、文字の妥当性を判定しない。

VADの補集合から0.5秒以上の無音候補を出し、文字の時刻がその全体をまたぐ場合に記録する。モデルやノイズによるVAD誤検出もあるため、これだけで時刻を修正・採用拒否しない。両方式の単位数、VAD外の単位数・秒数を並べるが、良い・悪いのスコアへ変換しない。

空の整列結果はunavailable、空のVADはvad_detected_no_speechという観測状態で扱う。不正なVADはValueError、不正な時刻単位はunavailableとして返す。人手正解との誤差は引き続き未測定。

出力先は新規ディレクトリに限定し、完了時だけreport.jsonを保存する。元ファイルは読み取り専用。VAD来歴にはパッケージ版・モデル実装ファイルのハッシュを記録する。モデル名だけでは重みの完全な来歴を保証しない。
