# 共通Evidence層 調査結果

- `FluencyExtractor.extract()` は内部でひらがな、VAD区間、ポーズ、モーラ時刻を作っていたが、モーラ時刻を返していなかった。v1で事実として返す。
- RangeはSudachiトークン化を所有していた。共有LinguisticEvidenceを受け取る入口を追加し、API/CLI経路の再トークン化をなくした。
- シリアライズされたEvidenceには学習者の文字起こしが含まれるため、永続キャッシュは明示的に有効化した場合だけ使う。
- `fluency_grade` は音源の事実ではなく解釈である。共通Bundleとそこから導くAPI/CLI事実から意図的に除外し、後段Judgeだけが評価する。
- キャッシュキーには抽出前に分かるモデル来歴が必要である。互換アダプターは旧抽出器の来歴を転送し、Fluency抽出器はSTT/VAD識別子を宣言する。
- この環境には `ruff` がない。コンパイル、全ユニットテスト、差分空白検査は成功した。
- 単体の `fluency.py` 表示からもS〜D gradeを削除し、どちらの経路でも評価を後段に限定した。
