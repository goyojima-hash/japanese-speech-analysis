# J-GRADE テスト指針・結果レポート（2026-08-04）

## 1. テストの目的

単に処理が動くかではなく、次の開発で何を直すべきかを判断するため、以下を確認した。

1. 正解が分かっている公式音源を適切に評価できるか。
2. 無音・雑音などを通常のA1として誤評価しないか。
3. AIごとの判定差を最終合議で吸収できるか。
4. 公式音源以外の外国人学習者・日本人会話も処理できるか。
5. 一部のAIが不完全な返答をしても、再試行または残りのAIで処理できるか。

## 2. 使用したデータ

### 正解付きデータ

国際交流基金「JFスタンダード」の公式ロールプレイ音源13件を使用した。各公式ページに記載されたCEFR/JFSレベルと課題達成度を比較対象とした。

- A2: 4件
- B1: 4件
- B2: 3件
- C1: 2件

出典一覧と音源・評価PDF・個別ページは `examples/jfs_roleplay_catalog.json` に記録している。

### 正解なしの実音声

- Creative Commons条件を確認した外国人日本語学習者の公開音声
- CC0の日本人会話音声
- リポジトリ内の外国人学習者音声3件

これらは人による正解レベルがないため、精度計算には含めず、実音声を処理できるかの確認にのみ使用した。

### 異常入力

- 10秒の無音
- 10秒の雑音
- 0.25秒の無音
- 誤検出確認用の1分の通常学習者音声

## 3. 公式13音源の結果

OpenAI・Anthropic・Geminiの3AIで評価し、最終合議結果を公式レベルと比較した。

| 指標 | 結果 |
| --- | ---: |
| 公式レベルと完全一致 | 7/13（53.8%） |
| 公式レベルから1段階以内 | 13/13（100%） |
| 最終処理まで完了 | 13/13（100%） |
| AIの不完全な返答 | 3件（Gemini） |
| 人による確認表示 | 3/13 |

### レベル別

| 公式レベル | 件数 | 完全一致 | 傾向 |
| --- | ---: | ---: | --- |
| A2 | 4 | 4/4 | 全件一致 |
| B1 | 4 | 2/4 | 2件をA2と判定 |
| B2 | 3 | 1/3 | 2件をB1と判定 |
| C1 | 2 | 0/2 | 2件をB2と判定 |

B2・C1は公式より低く出る傾向があった。ただし、今回の公式音源には試験官と受験者の両方の音声が含まれる。本番では質問を文字情報で渡し、評価音声を受験者の回答だけにする想定のため、現時点では話者分離機能を追加せず、本番形式の新しい音源を増やして傾向を再確認する。

## 4. 無音・雑音の修正結果

修正前は、無音・雑音・0.25秒の無音もA1として評価が完了していた。評価前の入力確認を追加した結果は以下のとおり。

| 音源 | 修正後 | 根拠 |
| --- | --- | --- |
| 10秒の無音 | 評価不能 | 発話0秒、文字起こし0文字 |
| 10秒の雑音 | 評価不能 | 発話0秒、文字起こし0文字 |
| 0.25秒の無音 | 短すぎる音声 | 最低0.5秒未満 |
| 1分の学習者音声 | 評価可能 | 発話34.3秒、発話率57.17%、文字起こし249文字 |

通常の学習者音声を誤って止めず、評価不能な3件だけをAI評価前に止められた。

## 5. 合議・再現性・障害時動作

同じ公式B1音源を3回評価した再現性テストでは、AI単体で1回だけA2が出たが、最終結果は3回ともB1だった。AIごとの差を最終合議で吸収する基本処理は動作している。

今回、GeminiのJSON返答が途中で切れるケースが3件あった。残り2AIで処理は継続し、人による確認が必要と表示された。

これを受け、以下を修正した。

- 不完全なAI返答の試行回数を最大2回から最大3回へ変更。
- 再試行時は理由120文字以内、根拠・注意点各3件以内とし、返答切れを起こしにくくした。
- API、一括テスト、ターミナル操作で異なっていた課題達成度のまとめ方を共通化した。
- 3AIがすべて異なる場合は中央、2AIが異なる場合は低い方を採用し、人による確認を必要とする。

## 6. 新しい実音声の結果

| 音源 | 結果 | この結果から分かること |
| --- | --- | --- |
| 外国人学習者の公開音声 | 3AIともA1、最終A1 | 外国人学習者の実音声でも3AI評価を完了できる |
| 日本人の公開会話 | 3AIともA1、最終A1 | 処理は完了するが、複数人・長い無音を含む音声では文字起こしが崩れる |
| 外国人学習者音声3件 | 音声処理から結果作成まで完了 | 異なる母語の学習者音声を読み込める |

正解レベルがないため、A1が正しいとは判断しない。今後は、本番と同じ「受験者だけの回答音声」で、人が事前にレベルを付けた新しいデータを増やす。

## 7. プログラム確認

- 自動テスト: 52/52成功
- 無音・雑音の実音声再テスト: 4/4想定どおり
- 公式13音源: 13/13で最終処理まで完了
- 実行形式: CLI（ターミナルから使う形式）を維持
- GUI（画面）の追加: なし

## 8. 次の判断

現段階では、評価調整機能を増やさず、以下を優先する。

1. 今回追加した再試行と共通集約ルールを実AIで継続確認する。
2. 本番と同じ受験者単独の新しい正解付き音源を追加する。
3. 公式13件と新しい音源の両方を再テストする。
4. B2・C1が低く出る傾向が本番形式の音源でも残るか確認する。
5. 一定方向のズレが残った場合にのみ評価調整を検討する。

話者分離は、本番で受験者だけを録音する設計なら不要なため、現時点の優先修正には含めない。文字起こし品質による自動確認機能も、判定基準が未定のためすぐには追加せず、新しい音源の結果から必要性を判断する。
