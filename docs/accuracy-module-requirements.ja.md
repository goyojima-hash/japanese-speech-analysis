# 正確さモジュール 要件

## 目的

正確さを、独立選択できる事実収集モジュールとして追加する。共有 `EvidenceBundle` を受け取り、`AccuracyFactPacket` を返す。スコア、CEFR/JFS、正誤、訂正案、LLM結論は出さない。

## 実装済みv1の対象

- CTC-ASRのモーラ／文字ごとの時刻、CTC argmax由来であること、モデル来歴、`unavailable` の較正状態を出す。
- 既存の共有Sudachiトークンから、表層・見出し語・読み・品詞・文字位置・局所パターンIDを出す。
- 呼び出し側が明示的に参照文を渡した場合のみ、正規化後の編集差分を出す。これは差分であって誤り判定ではない。
- 確率要約、信頼度較正、音素アラインメント、発音診断、参照文がない場合は未対応能力として明示する。

## 禁止事項

- LLM、文法訂正、発音スコア、正誤フラグ、CEFRレベルを出さない。
- 明示的な参照文なしに課題文・期待語彙と照合しない。
- 生のフレームlogitを保存しない。キャッシュは既存と同じく明示有効化時だけ使う。
- v1でMontreal Forced Alignerを必須依存にしない。

## 合格条件

- Accuracy単体でも、他モジュールとの組合せでも動く。
- ASR由来の値は常に `uncalibrated` と明示し、正しさとして出力できない。
- 参照差分は明示的な参照文がある時だけ出る。
- 未対応能力が捏造されず、理由付きで出力される。
