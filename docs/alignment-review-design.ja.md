# 時刻検証の試聴補助: 設計

`jgrade_eval/alignment_review.py`の独立CLIから、benchmark manifest・予測・正解テンプレートを読む。現行のevaluateを先に実行して不正な人手正解や重複音声を検出する。元音声ハッシュはデコード前後で照合する。

既存依存librosaで16kHz・monoに読み、soundfileでWAVを書き出す。記録長は元benchmarkと照合する。元音声上の秒数をサンプル位置に変換し、先頭はfloor、終端はceilで丸める。クリップの原点秒数をCSVに記録し、試聴音声内の時刻から元音声時刻へ戻せるようにする。

出力は新規フォルダに`clips/`・`review.csv`・`manifest.json`。ファイル名は連番だけにして、sample/segment IDをパスに使用しない。CSV文字列は表計算ソフトの数式として実行されないように保護する。JSON manifestには元の文字列を保存する。

機械候補のsuggested時刻だけを試聴範囲選択に使用する。正解start/endは絶対に補完しない。候補が無い場合は試聴クリップを省略し、元音声を聞く行を出力する。候補はモデル由来の区切りなので、クリップ外の境界やASR誤りを見逃さないよう元音声への参照を残す。今回CSVの自動取り込みや正解の自動承認は行わない。
